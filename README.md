# ✂ xImJxstinn Stream Clipper

Windows-App, die automatisch die besten Stellen aus Twitch-Streams findet und clippt (16:9 + TikTok 9:16).

**Download:** Oben auf **Code → Download ZIP**, entpacken, `start.bat` doppelklicken.  
Updates kommen danach automatisch.

Erkennt Highlights über Chat-Hype (ohne Bots, Begrüßungen, Raids), deine Stimme, „clip“ im Chat und lernt über 👍/👎 deinen Geschmack.
Mehr in `ANLEITUNG.txt`.

## Neue Version veröffentlichen
1. Dateien ändern
2. In `StreamClipper.pyw` `VERSION` hochzählen
3. In `version.json` die gleiche Version + `notes` eintragen und pushen

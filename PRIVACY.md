# Datenschutz – Stream Clipper / Privacy Policy

**Stream Clipper** ist eine private Desktop-App von xImJxstinn, die Clips aus den eigenen Twitch-Streams erstellt und auf den eigenen YouTube- und TikTok-Kanal hochlädt.

- Die App läuft ausschließlich lokal auf dem PC des Nutzers. Es gibt keinen Server und keine Datenbank des Entwicklers.
- Anmeldedaten (OAuth-Tokens) für YouTube und TikTok werden nur lokal in der Datei `uploads.json` gespeichert und nur an Google bzw. TikTok gesendet.
- Die App nutzt die YouTube Data API nur, um vom Nutzer erstellte Videos auf seinen eigenen Kanal hochzuladen und den Kanalnamen anzuzeigen.
- Es werden keine Daten an Dritte weitergegeben, verkauft oder für Werbung verwendet.
- Zugriff widerrufen: https://myaccount.google.com/permissions bzw. in den TikTok-App-Einstellungen; lokale Daten löschen: `uploads.json` löschen.

Kontakt: ximjxstinnfn@gmail.com

---

**English:** Stream Clipper is a private desktop app that runs locally. OAuth tokens are stored only on the user's computer and are only sent to Google/TikTok to upload the user's own videos to the user's own channels. No data is collected, shared or sold. Revoke access at https://myaccount.google.com/permissions. Contact: ximjxstinnfn@gmail.com

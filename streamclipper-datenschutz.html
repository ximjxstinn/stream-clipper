Datenschutzerklärung – Stream Clipper

für die Desktop-App „Stream Clipper“ von xImJxstinn

1. Was ist Stream Clipper?

Stream Clipper ist eine Windows-App, die aus meinen eigenen Twitch-Streams und Spielaufnahmen kurze Clips macht und sie – nur auf meinen ausdrücklichen Klick – auf meinen eigenen TikTok- und YouTube-Kanal hochlädt. Die App läuft ausschließlich lokal auf dem eigenen PC.

2. Welche Daten verarbeitet die App?

  • Anmeldedaten (OAuth-Tokens) von TikTok und YouTube – werden nur lokal in der Datei uploads.json auf dem PC gespeichert.
  • TikTok-Kontoinfos (Anzeigename, Benutzername, Profilbild, erlaubte Sichtbarkeitsstufen) über die TikTok-Schnittstelle – nur, um sie beim Posten anzuzeigen. Sie werden nicht gespeichert.
  • Die vom Nutzer erstellten Videoclips samt Titel und Hashtags – werden nur an TikTok bzw. YouTube gesendet, wenn der Nutzer das will.
  • Öffentliche Twitch-Daten (Stream-Status, Chat, Video) des eigenen Kanals – nur zur Erkennung von Highlights, lokal.

3. Was passiert nicht?

  • Es gibt keinen Server und keine Datenbank des Entwicklers – keine Daten verlassen den PC, außer zu TikTok, Google/YouTube und Twitch.
  • Keine Weitergabe, kein Verkauf, keine Werbung, kein Tracking, keine Analyse von Nutzerdaten.

4. Verwendete Schnittstellen

  • TikTok Login Kit und Content Posting API (Berechtigungen: user.info.basic, video.upload, video.publish)
  • YouTube Data API v3 (Upload in den eigenen Kanal) – es gelten zusätzlich die Google-Datenschutzerklärung.
  • Twitch API (Clips im eigenen Kanal)

5. Speicherdauer und Löschen

Die Tokens bleiben gespeichert, bis der Nutzer die Verbindung trennt oder die Datei uploads.json löscht. Zugriff jederzeit widerrufen: TikTok-App → Einstellungen → Sicherheit → Apps mit Berechtigung; Google: myaccount.google.com/permissions.

Privacy Policy – Stream Clipper

for the desktop app “Stream Clipper” by xImJxstinn

1. What is Stream Clipper?

Stream Clipper is a Windows desktop app that creates short clips from the creator's own Twitch streams and gameplay recordings and uploads them to the creator's own TikTok and YouTube accounts — only after the creator explicitly confirms each post. The app runs entirely on the user's own computer.

2. Data processed

  • OAuth tokens for TikTok and YouTube, stored only locally in uploads.json.
  • TikTok creator info (display name, username, avatar, allowed privacy levels) — only displayed on the posting screen, never stored.
  • Video clips created by the user plus title and hashtags — sent only to TikTok/YouTube when the user chooses to post.
  • Public Twitch data of the user's own channel — used locally to detect highlights.

3. What we don't do

There is no developer server or database. No data is shared, sold, used for advertising, tracked or analysed. Data only goes to TikTok, Google/YouTube and Twitch.

4. APIs used

TikTok Login Kit and Content Posting API (scopes user.info.basic, video.upload, video.publish), YouTube Data API v3 (see Google Privacy Policy), Twitch API.

5. Retention and deletion

Tokens are kept until the user disconnects or deletes uploads.json. Revoke access anytime in the TikTok app (Settings → Security → Apps with permission) or at myaccount.google.com/permissions.
